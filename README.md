# 问渠播放增强

问渠学堂课程回放的方向键增强（Edge 扩展）：

- `→` / `←` 短按：快进 / 快退 5 秒
- `→` 长按：按记住的倍速临时加速，松开恢复原倍速
- 长按期间 `↑` / `↓`：以 0.25× 调整加速倍速（0.5×–4×，长期保存）

## 安装

1. `edge://extensions/` 打开开发人员模式，加载解压缩的本文件夹。
2. 刷新课程回放页面。

## 设置

点扩展图标设置**长按触发时间**（10–500ms，默认 100ms），点「保存」。值存在 `chrome.storage.local`，全屏、刷新、重启浏览器后都保留。

## 测试
